# AI Module (JARVIS)

Dieses Modul kapselt die KI-Pipelines fuer:

- Strategie-Generierung
- Hyperparameter-Optimierung (Optuna)
- Modellselektion (z. B. XGBoost, NN)
- Reinforcement-Learning Workflows
- Overfitting-Kontrollen

`orchestrator.py` bildet die zentrale Einstiegsschicht fuer alle AI-Jobs.
