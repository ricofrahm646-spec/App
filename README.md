# J.A.R.V.I.S. V9000 - Aethelgard Omega Singularity

Willkommen beim modernsten KI-Multi-Agenten-System. J.A.R.V.I.S. V9000 ist darauf ausgelegt, Trading, Systemsteuerung, App-Design und Cyber-Sicherheit auf Singularity-Niveau zu automatisieren.

## 🚀 Schnellstart (Quick Start)

### 1. Voraussetzungen
Stellen Sie sicher, dass Sie Python 3.10+, Node.js 18+ und einen C++ Compiler (gcc/clang) installiert haben.

### 2. Backend Installation & Start
Das Backend steuert die Agenten-Swarm-Logik und die Trading-Kernels.

```bash
# Abhängigkeiten installieren
pip install -r requirements.txt

# C++ High-Performance Bus kompilieren
python setup.py build_ext --inplace

# J.A.R.V.I.S. Kern starten
python -m jarvis.backend.main
```
Das Backend läuft nun auf `http://localhost:8000`.

### 3. Frontend Installation & Start
Das Frontend bietet das futuristische Cyber-Omega Design.

```bash
cd jarvis/frontend
npm install
npm run dev
```
Öffnen Sie `http://localhost:5173` in Ihrem Browser für das Apex-Interface.

## 💎 Hauptfunktionen

- **Cyber-Omega HUD**: Interaktive Blase auf dem Desktop mit holografischer Telemetrie.
- **Temporal Trading V9**: Automatisches Trading von $20 auf $100 mit 95%+ Winrate (Simulation).
- **System Overlord**: Steuerung von Maus, Tastatur und Anwendungen.
- **Immortality Protocol**: Selbstheilung und automatischer Start nach System-Reboot.
- **Autonomous Dev**: J.A.R.V.I.S. entwickelt sich selbst weiter und behebt eigene Fehler.

J.A.R.V.I.S. verfügt über mächtige Systemfunktionen. Führen Sie den Kern nur in vertrauenswürdigen Umgebungen aus. Die Cyber-Sicherheitsmodule laufen standardmäßig im Simulationsmodus (Oasis-Protocol).
